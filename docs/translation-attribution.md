# Translation attribution

The interface translations bundled under `shared/src/commonMain/composeResources/values-*` were
originally imported from an upstream GPL-3.0 YouTube Music client. Their original authorship is
preserved in the resource-file headers and in Git history; please keep those headers when updating
or redistributing the translations.

The localized Hebrew catalog was completed for this build. KMP-specific translations are project
contributions, not part of the upstream import. All translations live in
`shared/src/commonMain/composeResources/values-*/strings.xml`. See [strings.md](strings.md) for the
catalog workflow.
