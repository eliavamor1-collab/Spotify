<div align="center">

<h1>Features</h1>

</div>

- YouTube Music playback with or without signing in
- Full Hebrew interface, plus translations in many other languages
- Material 3 Expressive design, custom fonts and alternate app icons
- No ads
- Lyrics with translation and romanization
- Downloads, caching, backups and playlist imports
- Discord Rich Presence and scrobbling through Last.fm and ListenBrainz
- Listen Together, casting and music recognition
- In-app updates from this repository's GitHub Releases

<h1>Releases</h1>

Every signed APK is built by GitHub Actions and published on the
<a href="https://github.com/eliavamor1-collab/Spotify/releases">Releases page</a> as
<code>Spotify.apk</code> and a versioned filename. To send an update, bump the version and push a
<code>v*</code> tag; the workflow builds, signs and publishes it automatically.
